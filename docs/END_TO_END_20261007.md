## Goal

Raw TACO hand/object observations + manually reviewed static Oracle schedule →
local padded Anchor synthesis → cuRobo only in RELAXED intervals → fresh,
uninterrupted PhysX rollout → actual-state trace/video downloaded locally.

The earlier three complete successful spatial trajectories used local artifacts
and feedback paths assembled during research iterations. They establish the
physical sequence, but do not establish an automatic raw-input end-to-end run.

## Changes

- One driver, `scripts/run_end_to_end.py`, connects preparation, local synthesis,
  observed-failure repair, artifact export, and independent final execution.
- Free bridges prepare the next core-entry pregrasp finger drive. Grasped
  bridges retain their current finger drive/preload.
- Canonical CORE entries come from the intended actual cuRobo predecessor.
  Its last padding frames are fixed physical synthesis context. Local fitting,
  Replay/MPPI/PPO and exported-core execution use that same reached boundary.
  The padded gate executes this physical pre-context plus local CORE/post-context
  without a reset; CORE/controller takeover matches the final runtime.
- Local repair can create stabilizing post-context command proposals without
  requiring a hand-picked old padded command file. Context still requires physics.
- `scripts/collect_end_to_end.py` downloads actual states and renders locally,
  including a source RGB / actual-state comparison. It preserves each source clock.

No sample-name control branches, new VLM segmentation, state teleportation,
temporal stretching, or replacement of failed results with reference animation.

### Controller and initialization contract

r147's gravity-moment compensation improved a free-hand tracking diagnostic,
but changed the controller used by the validated local library. r148/r150 then
replaced drive targets with measured poses. Measured body states retain physical
evidence; they are not equivalent command targets. In particular, removing
their drive offsets also removes the response that maintained loaded contact.

The next run restores the previously validated force-compensated PD controller
as the common default. Gravity-moment compensation is an explicit experimental
controller option and is part of the scene identity. Transport subtracts only
gravity terms actually supplied by that controller. Local initialization again
transfers validated **drive targets** in the source object's coordinate frame,
including nominal feedforward and finger preload. On the identical source and
clock, this reproduces the original local commands to numerical precision
(position 2.2e-16 m; hand 1.8e-15 rad; twist 1.1e-14 in native units).

This is an interface correction, not yet a new-source success result. It
does not assign the library's physical states to the new simulator; fresh
source-specific physical execution is still required for every artifact.
