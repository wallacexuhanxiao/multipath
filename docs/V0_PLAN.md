2. **Single Put-In scene.** Source `(put in, bowl, plate)/20231024_253`. Import its existing VLM BC schedule, cross-check the windows against contact and video, and reconstruct the object/target in the mounted-arm scene.
3. **XHand BC plus mounted arm.** Retain prior XHand finger BC. Convert each floating XHand root pose into a wrist pose for a mounted arm through a calibrated fixed transform and test IK, collision, tracking, and coupled PhysX grasp retention. If local coupled replay fails, use EgoEngine chunk repair with MPC and, where needed, local RL. Export physically verified BC entry/exit states and executable arm-plus-hand commands with provenance.
4. **BC/cuRobo schedule.** Import the VLM schedule from the existing selective-BC pipeline. The BC intervals are interaction controllers, seeded by verified EgoEngine-synthesized demonstrations when absent; every relaxed interval is a cuRobo planning window. Include prefix and suffix free motion, not just the gap between two BC windows. Match cuRobo YAML to the Isaac robot, map named arm joints and test collision-world parity; include carried-object collision geometry after grasp. Start and canonical end joints both checked.
5. **Local transport rollout.** Run cuRobo controls on a saved *actually reachable* PhysX grasp boundary; check actual bowl and hand states, contacts, collision and controller tracking. Local test cannot count as final output.
6. **Single complete rollout.** Reset only at task start. Execute the full cuRobo prefix → BC grasp → cuRobo transport → BC Put-In/release → cuRobo suffix, with physical boundary correction where needed. Require task-specific geometric/contact predicate, complete actual-state trace and video. Reject any reference animation, teleport, discontinuity, hidden reset or missing evidence.
